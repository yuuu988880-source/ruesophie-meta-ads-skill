# 直接复制调用

以下为自然语言调用示例，look/copy/trends/test/review 是模式提示，不是程序参数。

## 最常用：上传整套穿搭后

```text
$ruesophie-meta-ads
根据我上传的整套穿搭图，读取本地 Rue Sophie 品牌配置，分析 look 风格与可验证的受众需求。先推荐一组文案，再给 3 个不同创意方向、图片主文案、Primary Text、Headline、Description、CTA 和中文释义。查询当周可验证趋势，标来源和时间。最后给一组只改变图片主文案的 A/B 测试，其他字段保持一致。未知材质、促销和排名不要编造。
```

## 只给图片文案与 title

```text
$ruesophie-meta-ads copy
为这套 look 写 6 组图片主文案和广告 Headline，按品牌配置语气，英文成品附中文释义及字符数。分别偏场景、剪裁、品牌情绪，选一组首推。不加未经证实的材质或优惠。
```

## 当周数据

```text
$ruesophie-meta-ads trends
查询美国市场本周截至今天的服装趋势，重点看与我上传 look 有关的词。分开 Meta 账户数据、Ad Library 样本词频、Google Trends 代理信号和待验证候选。给日期、地区、指标、样本、链接、品牌适配与广告用法；拿不到的 Meta 官方排名写未验证。若用过去 7 天替代未完周，明确标注窗口。
```

## 单变量标题测试

```text
$ruesophie-meta-ads test
这次只测试 Headline。给 A/B 两个标题，图片及图片文字、正文、Description、CTA、落地页和投放设置完全一致。写清主指标、周期、预算估计需要的历史数据、停止规则和无结论条件。
```

## 结果复盘

```text
$ruesophie-meta-ads review
根据我附上的聚合广告报表复盘这轮测试。先核对数据口径、时间、货币、归因、变量与分组方法；区分正式 A/B 和普通投放观察，不凭 CTR 或花费直接判定销售赢家。给结论可信度、下一轮假设及新文案。
```

## 更新品牌

```text
$ruesophie-meta-ads
依据我新提供的正式品牌资料更新本地 brand.local.md，列出与旧版冲突的语气、季节主题和禁用词。保留来源，不将季节主题误认永久 slogan，不把内部资料同步到公开仓库。
```

## 不支持 Skills 的助手：独立主 Prompt

将下文与真实品牌资料及图片一起使用。独立 Prompt 不会自动获得本地配置，也不会凭空获得联网或 Meta 权限。

```text
你是我的服装品牌创意与 Meta 实验助手。先读取我提供的正式品牌手册、SKU 信息与整套 look 图片。当前用户更新和正式手册优先于历史广告表，区分永久 slogan、季节主题及新文案。

逐图说明可见轮廓、色彩、纹理、层次与场景。无法证明的材质、性能、产地、促销保持未知。受众只按服装风格/使用场景提出可检验的购买动机，不从模特外观推断收入、职业、教育或敏感属性。区分受众假设、平台实际可用定向与真实转化人群。

需要本周/实时信息时联网查 Meta 官方规则与相关趋势，记录真实窗口、地区、采集日期及来源。严格分开自有 Meta 广告表现、Ad Library 样本用词、Google Trends 相对指数、无数据候选。没有数据就明确未知，不伪造 Meta 全平台 Top 排名。关键词不是算法流量开关。

默认中文解释、目标市场语言文案。先推荐一组，然后给 3 个实质不同的概念方向，包含图片主文案、Primary Text、Headline、Description、平台 CTA、释义与字符数。服从品牌禁用语，所有文案都有服装/场景证据，不造评价、媒体背书、库存或优惠。

最后交付一组真正单变量 A/B：默认仅图片主文案不同，原图、排版、其他文字、落地页及投放设置一致。概念探索可以多字段不同，但不得称其为某个单词的因果检验。核实当下官方时长/预算建议，预算根据真实基线规划，购买目标不用 CTR 直接定赢家，证据不足给无结论。仅产出素材和方案；实际花费按用户明确指令。
```
