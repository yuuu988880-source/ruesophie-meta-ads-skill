# 当周关键词研究

## 时间口径

读取当前日期/时区。默认本周为周一至当前（WTD，未完周），也可提供过去 7 个完整日，不能混用。目标美国不等于数据时区自动美国；记录提供方时区。与前周比较要使用相同天数、完整性、采样/归一化设置，展示两个窗口。市场分开研究，商品季节与研究日期独立。

## 分开四种证据

| 来源 | 能支持 | 不能支持 |
| --- | --- | --- |
| Meta 自有账户汇总 | 该账户和广告在指定归因口径下的表现 | 全平台热词排名；某个单词的独立因果效果 |
| Meta Ad Library | 筛选条件下可见在投广告、用词与样式 | 商业广告真实 ROAS/CPA/转化；久投不等于盈利 |
| Google Trends 等原生趋势工具 | 对应平台/地区/窗口的相对搜索或内容信号 | Meta 转化、Meta 热词榜、可选定向兴趣 |
| 图片与品牌候选词 | 下一步研究/测试优先级 | 实时热度、增长率、官方名次 |

默认表名“本周可验证信号与候选词”。只有数据确实支持排名指标和覆盖范围时写“该样本 Top N”。未取得数据时写“未获得可验证的 Meta 全平台服装关键词周榜”，不要断言这种数据永远不存在。

## 研究流程

1. 从 look 生成品类、轮廓、场景、季节/配色候选，每词有图像/SKU 依据。
2. 搜索 Meta 官方 Engineering、Business、Blueprint、Transparency 的最新相关更新，区分发布与采集日期。只引用实际读到的支持性内容。登录墙/429/验证码是访问失败；可改用指定 Chrome 的原生 UI 或已连接浏览器读取，不能绕过访问控制。
3. Ad Library 记录国家、类别、活动状态、检索词/广告主、筛选条件、采集时间、广告 ID/链接、语言、开始日期及用词。按广告 ID 去重，重复素材变体归组，披露抽样方式和偏差。
4. 词频用固定短语匹配规则，报告含词去重广告数 n、总数 N、n/N、独立广告主数。某周抓到的在投样本不等于本周新增广告，更不是消费者需求。不同搜索样本不无校正合并排名。
5. Google Trends 使用同地区、时间、类别、搜索类型及 term/topic 口径，保存来源链接/导出。0–100 是相对兴趣，不是搜索量。两份独立归一化结果不能直接算周增幅或跨组排名；多批次须共同锚点/校准。零/低量不是需求为零；分母零时增长为 N/A。不从曲线高度估计精确数字。
6. 原始聚合数据保留本地，只引用实测值，不虚构 API 权限或抓取数量。无网络/限流时继续完成候选词与文案。

缺值填“未取得”，缺排名填“未验证”，不能用 0 代替。仅风格相关度可给高/中/低优先级，并标“编辑判断”。禁用热词只放研究区，广告映射为品牌许可语言。

每次实时请求重新检查来源并标“截至 YYYY-MM-DD HH:mm 时区”；缓存只能作为历史基线。Skill 不持续监听，不会自行按周运行；定期自动更新需用户另行明确要求与排期。
