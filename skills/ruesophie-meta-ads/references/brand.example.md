# 品牌本地配置模板

复制为同目录 `brand.local.md` 后填写真实信息；此文件本身不代表品牌事实。

- 品牌名称：由使用者提供。
- 默认市场/语言：未指定，使用时说明假设。
- 永久 slogan：未确认。
- 季节主题及适用系列：未确认。
- 正式资料位置、版本、日期：由使用者提供。
- 品牌定位/语气/价值：由正式手册提炼。
- 允许词与禁用词：只记录明确要求，标记来源。
- 已确认产品事实：按 SKU 逐项列证据，不推广到全系列。
- 促销、运费、库存、背书：未经当前证据核实一律不采用。
- 历史文案：区分已批准、旧草稿、冲突条目。
- logo 文件：本地路径；保持既有资产，不把图形文件开源。
- 受众：区分用户指定、真实数据支持、待测试候选。

更新本配置时保留事实来源；不因一次广告表现自动改写永久品牌定位。
