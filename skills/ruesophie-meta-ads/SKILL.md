# Rue Sophie Meta Ads

把整套 look 的可见特征转译为穿着场景、品牌语言和可验证的广告假设。默认中文解释、目标市场语言成品。用户发图调用时直接完成 look 模式。

## 品牌与输入

先读本 Skill 的 `references/brand.local.md`（如存在）及用户当前品牌资料。无本地配置时参考 [品牌模板](references/brand.example.md)，但不把模板当品牌事实。优先级：用户明确更新 > 当前适用正式手册 > 已确认 SKU 信息 > 旧广告表 > 外部趋势。冲突简要说明一次。

市场未给出时使用品牌配置；仍缺失暂按美国、英语并注明假设。预算、价格、落地页、SKU 信息缺失时保留未知，不阻塞能完成的文案。没有图片可做趋势/品牌文案，不能声称看过 look。

分清永久 slogan、季节主题、已有广告标题与本次新句子。季节主题只用于对应系列；商品季节不明时不强行贴当前季节。品牌禁用语即使热门也不能进入成品，可保留为研究检索词。

## 模式

- `look` / 发图：图片证据 → 受众假设 → 当周研究 → 创意方向 → 单变量 A/B 对。
- `copy` / 改文案：按品牌语气改图片文案及广告字段，保留已证实事实；无须强行做趋势研究。
- `trends` / 本周热词：读 [趋势研究](references/weekly-research.md)，核实时间、地区和数据口径。
- `test` / 测试方案：读 [实验规则](references/meta-testing.md)，区分探索与验证。
- `review` / 复盘：按实验规则的复盘部分处理真实汇总数据，区分因果与观察。

自然语言即可指定模式，不要求填写表单。声称“最新/实时/本周”前重新检索；[来源记录](references/sources.md) 是入口，不是永久最新知识。

## 看图与受众

打开每张可访问图片，按 look 编号；区分同一套不同角度和不同套穿搭，不确定则说明分组假设。提取主单品、轮廓/比例、配色、可见纹理、层次、配饰、场景、留白和一个主视觉卖点。标记「可见」「用户/SKU 已证实」「推测」，给高/中/低可信度及理由，不编造概率。

照片不能证明羊绒/真丝/羊毛含量、产地、手工、环保认证、售价、耐用年限、弹力或舒适性能。静态垂坠外观不是性能实测。

分析服装，不根据模特外观推断身份、财富、职业、教育、健康或其他敏感属性，不以摄影地点/奢侈配饰证明受众收入。

默认给 2–3 个购买动机不同的受众假设，每个写：场景需求、风格偏好、图像依据、购买顾虑、文案角度、可信度、验证方式。例：“希望通勤与晚餐自然过渡的穿着者”；不能把职业/收入画像说成看图事实。

分开创意服务人群、平台可选定向、转化数据验证人群。年龄段/职业只有在用户或真实数据支持时作为规划条件。历史兴趣表只作候选池；没有当前 Ads Manager/有效接口证据，不声称兴趣可用，不编兴趣 ID、覆盖人数。Advantage+ 的建议和硬控制按当前账户/地区核实。

## 研究与文案

按趋势研究区分 Meta 自有数据、Ad Library 样本、Google Trends 代理信号和无数据候选。每个数值有来源、真实窗口、采集时间、地区、样本和限制。拿不到数据时完成文案，热度/排名/增长率写未知。

不要把关键词当 Meta 搜索竞价词，也不要宣称堆词触发 Andromeda/GEM 流量开关。官方算法事实与我们的营销建议分开。

默认提出 3 个实质不同的创意方向，可选场景转换、轮廓细节、品牌情绪，随图片调整。每方向关联 look、受众动机、画面证据、品牌支柱。句子须有商品/场景锚点，避免全组空泛形容词。

交付两层内容：

1. **概念探索**：不同叙事的完整广告，可改变多个字段，明确不能归因到某个词。
2. **主测试 A/B**：默认只改图片主文案。图片、字体、字号、位置、logo、正文、Headline、Description、CTA、落地页和投放设置锁定。只测 Headline 时则锁定图片及其他字段。逐项给 A/B 的相同值与唯一差异，不能声称单变量却换整套文案。

每条包含 look ID、概念 ID、图片主文案 Overlay、可选副文案、Primary Text、Headline（广告 title）、Description、平台 CTA、中文释义。显示英文字符数（含空格）。Description 自由文案不是平台按钮名。

自定可读性目标：Overlay 常用 3–7 英文词、最多 2 行；Headline 优先约 40 字符以内，必要时给短版；Primary Text 有信息量的开头，可给长版。以上不是 Meta 全版位硬限制，核实当前指南和预览。Headline/Description 某些版位可能不展示，关键信息在图/正文中也要成立。

排版按原图留白，保护衣服轮廓、面部和 UI 覆盖区。4:5、1:1、9:16 是候选比例，裁切需看图和核验版位；不要宣称统一固定安全区或通用 20% 文字禁令。保持既有 logo 比例，不凭空重画。只要文案时交付文字/排版说明；要求实际成图时调用可用设计/图像工具并验证结果，不能把说明冒充成图。

## 实验与交付

按实验规则给主指标、固定项、变量、周期、预算依据、停止条件和胜出/无结论标准。不承诺精准命中、ROAS 或必出爆款。默认产出素材与方案，实际投放/预算/花费操作按当次明确授权。

默认输出顺序：首选文案与理由；look 证据/受众表；研究日期及分来源趋势表；探索广告表与完整单变量 A/B 表；实验卡。英文成品和中文分析分开。用户只要标题等短输出时按需求缩短。

交付前核对品牌用语、SKU 事实、图像依据、字符数与 A/B 唯一变量。删除未证实促销、运费、库存、媒体背书、评价数、成分和性能承诺。成品无占位符或分析标签。样本不足时输出“无结论”，不强选赢家。

开源只发布通用 Skill、模板、公开来源；`*.local.md`、原图、内部文档、广告导出及缓存保留本地，除非用户明确指定这些资料也可公开。

若需机器核对文案字符数和已列固定项，可把 A/B 交付保存成 JSON 后运行 `scripts/check_ab_pair.py <文件路径>`。支持字段与输入示例见脚本；检查仅验证声明数据，不证明真实账户配置一致。
